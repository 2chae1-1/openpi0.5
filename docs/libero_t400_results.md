# π0.5 LIBERO CPU–T400 측정 결과

- **마스킹된 빈 카메라 제외** — 원본 모델의 동일 관측에서 추론 중앙값이 10.363초에서 7.471초로 **27.9% 감소**했다. Gemma 입력은 968개에서 712개 토큰으로 줄었고, 동일 노이즈에서 액션 출력의 최대 절대 차이는 약 \(2.0\times10^{-7}\)이었다. 이 수치는 `98f124f` 기반의 서버 실험 코드에서 측정했다. 저장소의 기존 구현은 `token-compression/vision-baseline`에 있다.
- **언어 FFN 10% 프루닝** — 별도 측정에서 전체 파라미터가 **5.01% 감소**했고, 동일 관측 추론 중앙값은 11.799초에서 10.855초로 **8.0% 감소**했다. `libero_spatial` 태스크 0의 초기 상태 7개에서 원본과 프루닝 모델이 각각 7/7 성공했다. 구현은 `pruning/language-ffn-baseline`에 있다.
